# FirstHit v1.0

**FirstHit** es un addon para **World of Warcraft 3.3.5a (WotLK)** que rastrea y registra quién es el primer jugador en golpear a un jefe (boss).

---

## 🚀 Funcionalidades

- **Registro Automático**: Detecta al instante qué jugador realiza el primer ataque o genera la primera amenaza sobre un jefe.
- **Anuncios Personalizables**: Puede configurarse para anunciar en el chat de banda, grupo o de forma local quién hizo el "First Hit".
- **Interfaz Ligera**: Consumo mínimo de recursos, diseñado para no interferir en tu rendimiento en combate.

---

## 🛠️ Instalación

1. Copia la carpeta `firsthit` en `World of Warcraft\Interface\Addons\`
2. Asegúrate que la carpeta se llame exactamente `firsthit`
3. Actívalo en el menú de Addons al iniciar el juego

---

## 📖 Uso Rápido

- El addon funciona de forma automática en cuanto entras en combate.
- Utiliza el comando `/firsthit` o `/fh` en el chat para abrir las opciones de configuración y elegir dónde quieres que se anuncien los resultados.
